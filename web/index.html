02

Read the model’s output

The model returns two softmax scores that sum to 1. A fixed threshold of 0.5 turns them into a label.

03

See where the model looked

Grad-CAM weights the last convolutional block’s feature maps by how strongly they push the chosen class’s logit up. Bright regions influenced the output. That does not make them correct.
