Project description · An explainable-AI laboratory for chest radiographs

XRayLens AI

A pneumonia classifier gives you an answer. XRayLens shows how it got there, how far to trust it, and where it breaks.

Research & education only
Not for diagnosis

01 Problem

Medical-imaging AI is often presented as one impressive accuracy number. That number can come from testing a model on images it was trained on. Saliency heatmaps then look convincing even when the model relies on text markers or image borders. Students, clinicians-in-training and the public rarely get a way to question a model's output.

02 Solution

XRayLens is an interactive lab built around a real, publicly released ResNet-50 pneumonia classifier. It turns each prediction into a four-step investigation, and it treats the evaluation as a product feature, not a footnote.

  • Choose from 8 teaching cases picked by fixed rules from the evaluation, or upload PNG/JPEG/DICOM.
  • Read the label, both scores, logit margin and saturation, alongside how 400 external adult images scored.
  • Explain with Grad-CAM for either class. Heat on lungs, image frame and padding is always shown against area share. A live randomisation sanity check (Adebayo et al. 2018) shows whether the map depends on the learned weights.
  • Stress-test with 8 anatomy-preserving edits (crop, noise, burned-in marker, inversion…), re-scored live.
  • Reliability dashboard: leakage comparison, live threshold explorer, ROC, calibration, robustness, limitations.

03 Technical approach

Python 3.12 · PyTorch · Streamlit · scikit-learn · pydicom, plus a static web build running the same model in the browser with ONNX Runtime Web (bit-exact Pillow preprocessing, scores within 5×10⁻⁶ of PyTorch). Model: Purino/resnet50-chest-xray-pneumonia, pinned to a Hub commit, with preprocessing tested for exact parity with the model card's reference code. Grad-CAM is implemented from scratch with hooks on layer4 and back-propagates the logit difference, because this model's softmax saturates and softmax gradients vanish. 20 automated tests cover preprocessing, input handling, Grad-CAM properties and metric correctness. Every dataset is pinned and sampled with a fixed seed.

05 Limitations

No valid in-distribution test exists, because the published weights were refit on every Kermany image. External cohorts are adults, so population shift and generalisation error are confounded. RSNA “lung opacity” is not confirmed pneumonia. Samples are modest, so all metrics carry 95% CIs. Grad-CAM is a coarse view of one layer. Not clinically validated, and not a medical device.
